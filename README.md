# Raspberry Pi Bandwidth Controller (PPPoE)

TP-Link Archer C6-এর সাথে Raspberry Pi ব্যবহার করে ডিভাইস ভিত্তিক ব্যান্ডউইথ কন্ট্রোল সিস্টেম।

## Features
- Per-device Download/Upload limit
- Device Block / Unblock
- Simple Web Dashboard
- PPPoE compatible

## Requirements
- Raspberry Pi 4/5
- PPPoE connection
